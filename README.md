# useaImpedanceAnalysis
For analyzing the impedance data measured from implanted electronics via the Summit(Ripple Neuromed).

To run analysis:

Run "my_data = analyzeAllImpedance(folder_path)" where folder_path is the parent folder containing all of the impedance files in separate folders.

Impedance files should be named according to the "A_USEAx+B_USEAx+C_USEAx+D_iEMG" convention.
